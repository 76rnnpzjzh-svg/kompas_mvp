# Компас — ИИ-навигатор первых 30 дней в России для иностранных студентов

Команда «Крейсер» · Академия финтеха ВТБ 2026 · трек «Финтех без границ: банк будущего для бизнеса и клиентов»

> Студенческий конкурсный проект. Не является официальным продуктом ВТБ; банковские сценарии показаны как концепция для пилота.

Компас ведёт иностранного студента от письма о зачислении до первой покупки картой ВТБ:
персональный план со сроками (миграционный учёт, медосвидетельствование, SIM и Госуслуги, СНИЛС, банковская карта),
ответы на родном языке только по проверенной базе со ссылкой на источник, передача сложных вопросов человеку.

**Демо:** откройте `web/index.html` в браузере или ссылку GitHub Pages из раздела About репозитория. Ключи не нужны.

## Зачем

Опрос 20 иностранных студентов (спринт 1, 4 языка) показал:
- главная боль первого месяца — бюрократия: учёт (9 из 20), медосвидетельствование (8), СНИЛС и Госуслуги (7); карту трудной назвал 1;
- банк выбирают в первые 7–14 дней по совету земляков (14 из 20) — Компас приходит раньше, через вуз;
- больше всего ценят план со сроками, напоминания и ответы на родном языке (по 8 из 20).

## Что умеет MVP (спринт 1)

| Модуль | Где в коде | Как работает |
|---|---|---|
| Движок сроков | `kompas/plan.py`, `kompas/data/rules.yaml` | Сроки считают правила, а не языковая модель. Учёт ЕАЭС (30 дней), исключения (Беларусь). Дата въезда необязательна |
| Проверенная база знаний | `kompas/data/kb.yaml` | 8 карточек на ru/en/zh, у каждой источник и дата проверки |
| Поиск | `kompas/retriever.py` | BM25 по символьным n-граммам (работает для кириллицы, латиницы и китайского без моделей) + проверка ключевых слов против ложных срабатываний |
| Ограничители | `kompas/guard.py` | Маскирование паспорта, телефона, карты, почты до отправки в модель; отказ на вопросы об обходе проверок банка и валютного контроля |
| Передача человеку | `kompas/assistant.py` | Нет уверенного ответа в базе → вопрос уходит в международный отдел вуза |
| Языковая модель | `kompas/llm.py` | По умолчанию без модели (ответ = проверенная карточка). Опционально GigaChat API или любая модель в контуре банка через OpenAI-совместимый API (vLLM, Ollama, открытые веса GigaChat / Qwen) |
| Веб-демо | `web/` | Тот же алгоритм в браузере (`engine.js`), данные из той же базы; RU / EN / 中文; работает на телефоне |
| API | `kompas/api.py` | `POST /api/plan`, `POST /api/ask` |

## Контроль качества ИИ

`eval/questions.yaml` — размеченный набор вопросов на трёх языках: что должно найтись, что должно уйти человеку, на что нужно отказать.

```
python eval/run_eval.py
Вопросов: 34  Верно: 34  Точность: 100%   (ru 13/13, en 11/11, zh 10/10)
Опасных ошибок (ответил там, где должен был отказать или передать человеку): 0
```

Набор маленький и составлен командой; в спринте 2 пополняем его формулировками из интервью. Проверка запускается в CI на каждый коммит
и помечает сборку как упавшую, если точность ниже 90% или появилась опасная ошибка.

## Запуск

```bash
pip install -r requirements.txt
pytest -q                          # 10 тестов
python eval/run_eval.py            # качество ответов
uvicorn kompas.api:app --reload    # http://localhost:8000
```

С моделью (необязательно): скопируйте `.env.example` в `.env`, выберите `KOMPAS_LLM=gigachat` или `openai_compatible`.
Модель получает только вопрос с замаскированными данными и одну проверенную карточку; при сбое модели ответ берётся из карточки.

После правки `kompas/data/*.yaml` обновите данные демо: `python scripts/export_web_data.py`.

## Архитектура и путь к пилоту

```
Канал (веб-чат · MAX · Telegram · WeChat)
        │
   Ограничители: маскирование ПДн, запрещённые темы
        │
   ┌────┴──────────────┬───────────────────┬───────────────────┐
 Движок сроков     Поиск по базе      Модель в контуре     Действия в банке
 (правила)         (со ссылками)      банка (on-prem)      (API: заявка, запись)
        │
   Передача человеку (международный отдел / оператор банка)
```

| Сейчас (MVP) | Пилот в банке |
|---|---|
| BM25 по n-граммам | эмбеддинги BAAI/bge-m3 + Qdrant в контуре банка |
| без модели / GigaChat API | GigaChat или Qwen on-prem через vLLM |
| regex-маскирование | + NER (natasha, microsoft/presidio) для ФИО и адресов |
| демо-кнопка записи | API записи в отделение и предзаявки на карту ВТБ |
| данные в браузере | БД в РФ (152-ФЗ, ч. 5 ст. 18), согласие, журнал ответов |

## Безопасность и данные

- В репозитории нет и не должно быть ключей: они читаются только из переменных окружения, `.env` в `.gitignore`.
- Каждый коммит проверяется [gitleaks](https://github.com/gitleaks/gitleaks) в CI; локально — `pre-commit install`.
- Данные респондентов опроса в репозиторий не кладём.
- Ответы не являются юридической консультацией; сроки сверяются с международным отделом вуза.
